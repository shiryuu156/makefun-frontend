A fast, dependency-free static frontend for make.fun: live bounty board with pots, entry fees and time left, bounty pages with rewards and rules, leaderboards, and public profiles — all from make.fun's public API, no sign-in, no build step. First load is 8 files, 12.7 KB gzipped.

## Run it

```sh
python3 -m http.server --directory app 8000
```

Then open http://localhost:8000 in desktop Chrome.
